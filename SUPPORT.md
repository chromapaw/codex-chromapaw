# Support

## Start here

1. Read the [README](README.md) and run `python scripts/platform_capabilities.py --json`.
2. For Windows activation or recovery, follow [Windows Runtime Beta](docs/WINDOWS_RUNTIME_BETA.md).
3. For macOS limitations, read [macOS compatibility](docs/MACOS_COMPATIBILITY.md).
4. Remove local paths, task names, screenshots, tokens, debugging ports, and private artwork before sharing diagnostics.

## Choose the right channel

- Usage questions and ideas: [GitHub Discussions](https://github.com/chromapaw/codex-chromapaw/discussions).
- Reproducible bugs: use the [bug report form](https://github.com/chromapaw/codex-chromapaw/issues/new?template=bug_report.yml).
- New Codex version reports: use the [compatibility report form](https://github.com/chromapaw/codex-chromapaw/issues/new?template=compatibility_report.yml).
- Feature proposals: use the [feature request form](https://github.com/chromapaw/codex-chromapaw/issues/new?template=feature_request.yml).
- Security vulnerabilities or confidential conduct reports: use [private vulnerability reporting](https://github.com/chromapaw/codex-chromapaw/security/advisories/new), never a public issue.

## Support boundary

Skin and pet package generation is separate from installation and activation. Windows live skin activation is experimental and exact-version gated. macOS live skin activation is not implemented. Pet generation requires a compatible `hatch-pet` workflow. Please include the machine-readable capability report when asking for compatibility help.
